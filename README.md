# AI-Driven Cultural Recommendation System

## Dissertation Prototype

This Streamlit prototype demonstrates the recommendation
system developed for the postgraduate research project:

**Design and Development of AI-Driven Cultural Recommendation
System for Digital Marketplace**

## Frozen Recommendation Configuration

The prototype uses the selected configuration from the
recommendation-system development and evaluation stages:

- Content-Based Filtering: 0.20
- Profile-Based KNN: 0.20
- Cultural Affinity: 0.60
- KNN neighbours: 5

No model retraining or hyperparameter tuning is performed
within the prototype.

## Dataset

The recommendation-development population contains:

- 50,000 products
- 10 synthetic user profiles
- 500,000 user-product recommendation records

## Main Components

1. Content-Based Filtering
2. Profile-Based KNN preference transfer
3. Profile-Ontology Cultural Affinity
4. Hybrid score fusion
5. Cultural eligibility gating

## Scope

The prototype focuses on recommendation intelligence and
cultural product discovery.

It does not implement:

- payments
- checkout
- inventory management
- logistics
- vendor management
- auctions
- loyalty systems
- CRM

## Development

The application is being developed incrementally as part
of the dissertation prototype phase.
